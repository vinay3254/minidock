# minidock v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a root-required Rust runtime that runs trusted local rootfs tarballs in PID/mount/UTS/IPC namespaces with cgroups-v1 CPU and memory limits.

**Architecture:** A thin clap binary translates commands into library types. `image`, `state`, and `cgroups` are independently testable host-side modules; `container` owns the unsafe namespace, mount, pipe, and signal lifecycle. A launcher remains the parent of PID 1 and relays status to the host parent, which attaches PID 1 to cgroups before allowing the command to start.

**Tech Stack:** Rust 1.70+, `anyhow`, `clap`, `nix`, `libc`, `serde`, `serde_json`, `tar`, `flate2`, `uuid`, `time`, `tempfile` (dev dependency).

**Spec:** `docs/superpowers/specs/2026-09-06-minidock-v1-design.md`

## Global Constraints

- Linux only; require root or the capabilities needed for namespace, mount, and cgroup operations.
- Support Rust 1.70+.
- Accept trusted local gzip-compressed tar rootfs images only; do not add OCI, registry, networking, overlayfs, rootless mode, or cgroups-v2 support.
- Refuse hosts that provide only cgroups v2; never silently omit configured resource limits.
- Keep all runtime state below the current user's `~/.minidock`; validate UUID IDs before path construction.
- Default tests must be unprivileged and must not change `/sys/fs/cgroup`; privileged tests are `#[ignore]`.

```rust
// src/image.rs
pub fn extract_rootfs(image: &Path, destination: &Path) -> anyhow::Result<()> {
    std::fs::create_dir_all(destination)?;
    let decoder = flate2::read::GzDecoder::new(std::fs::File::open(image)?);
    let mut archive = tar::Archive::new(decoder);
    for entry in archive.entries()? {
        let mut entry = entry?;
        let path = entry.path()?;
        validate_archive_path(&path)?;
        reject_unsafe_entry_type(entry.header().entry_type(), &path)?;
        entry.unpack_in(destination)
            .with_context(|| format!("extracting {}", path.display()))?;
    }
    Ok(())
}

fn validate_archive_path(path: &Path) -> anyhow::Result<()> {
    anyhow::ensure!(!path.is_absolute(), "archive path is absolute: {}", path.display());
    anyhow::ensure!(path.components().all(|part| !matches!(part, std::path::Component::ParentDir)),
        "archive entry escapes rootfs: {}", path.display());
    Ok(())
}
```

Reject block/char devices, FIFOs, and hard links. For symlinks, reject absolute
targets and targets containing `..`; use a non-following walk (`WalkDir` is not
needed—use `std::fs::read_dir` recursively) to build the archive with relative paths.
Before writing `output`, canonicalize `context` and reject an output path within it.
Wire `Command::Build` to `build_image` and print the output path only after success.

```rust
// src/state.rs
#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub enum ContainerStatus { Running, Exited, Stopped }

#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub struct ContainerState {
    pub version: u8, pub id: uuid::Uuid, pub pid: i32, pub cgroup_path: PathBuf,
    pub rootfs: PathBuf, pub command: Vec<String>, pub hostname: String,
    pub detached: bool, pub started_at: time::OffsetDateTime, pub status: ContainerStatus,
}

pub struct StateStore { root: PathBuf }
impl StateStore {
    pub fn from_current_user() -> anyhow::Result<Self> {
        let home = std::env::var_os("HOME").context("HOME is not set")?;
        Ok(Self::at(PathBuf::from(home).join(".minidock")))
    }
    pub fn at(root: PathBuf) -> Self { Self { root } }
    pub fn save(&self, state: &ContainerState) -> anyhow::Result<()> {
        let state_dir = self.root.join("state");
        std::fs::create_dir_all(&state_dir)?;
        let target = state_dir.join(format!("{}.json", state.id));
        let temp = state_dir.join(format!("{}.json.tmp", state.id));
        let mut file = std::fs::File::create(&temp)?;
        serde_json::to_writer(&mut file, state)?;
        file.sync_all()?;
        std::fs::rename(temp, target)?;
        Ok(())
    }
    pub fn load(&self, id: uuid::Uuid) -> anyhow::Result<ContainerState> {
        let file = std::fs::File::open(self.root.join("state").join(format!("{id}.json")))?;
        Ok(serde_json::from_reader(file)?)
    }
    pub fn list(&self) -> anyhow::Result<Vec<ContainerState>> {
        let state_dir = self.root.join("state");
        if !state_dir.exists() { return Ok(Vec::new()); }
        let mut states = std::fs::read_dir(state_dir)?
            .filter_map(Result::ok).filter(|e| e.path().extension().is_some_and(|x| x == "json"))
            .map(|e| serde_json::from_reader(std::fs::File::open(e.path())?).map_err(Into::into))
            .collect::<anyhow::Result<Vec<ContainerState>>>()?;
        states.sort_by_key(|state| state.started_at);
        Ok(states)
    }
}
```

Serialize commands as UTF-8 strings only after rejecting non-UTF-8 command
arguments in CLI parsing; do not attempt to serialize `OsString` directly. Use
`nix::sys::signal::kill(Pid::from_raw(pid), None)` for liveness: `ESRCH` means exited,
`EPERM` means alive. Validate all load/list IDs as UUID values. Write state to
`<id>.json.tmp`, call `sync_all`, and rename in the same `state` directory.

impl ContainerCgroups {
    pub fn attach(&self, host_pid: i32) -> anyhow::Result<()> {
        for path in [self.memory.as_ref(), self.cpu.as_ref()].into_iter().flatten() {
            std::fs::write(path.join("tasks"), format!("{host_pid}\n"))?;
        }
        Ok(())

- [ ] **Step 3: Implement the parent/launcher/init lifecycle in explicit phases**

```rust
pub struct RunRequest {
    pub image: PathBuf, pub memory_bytes: Option<u64>, pub cpu_percent: Option<u8>,
    pub hostname: String, pub detached: bool, pub command: Vec<String>,
}

enum StatusMessage { InitPid(i32), Ready, Error(String), Exit(i32) }

pub fn run(request: RunRequest, store: StateStore) -> anyhow::Result<i32> {
    require_root()?;
    // create UUID/state paths; extract; discover/create cgroups; establish pipes
    // fork launcher; receive InitPid; attach cgroups; atomically save state; release init
    // wait for Ready/Error, then return or relay Exit according to detached mode
}
```

In the launcher, call `unshare(CLONE_NEWPID | CLONE_NEWNS | CLONE_NEWUTS |
CLONE_NEWIPC)` and then fork exactly once; the resulting child is namespace PID 1.
Keep the launcher alive to `waitpid` init and forward `Exit(code)` to the original
parent. In init, call `MS_REC | MS_PRIVATE` on `/`; bind-mount rootfs to itself;
create `.old_root`; construct nul-free `CString` values for `rootfs` and
`rootfs/.old_root`; invoke `libc::syscall(libc::SYS_pivot_root, rootfs_ptr, old_root_ptr)`;
`chdir("/")`;
lazy-unmount and remove `/.old_root`; mount `proc` at `/proc`; set the hostname;
wait for the one-byte release gate; report `Ready`; then run the signal-forwarding
reaper loop. Close unused pipe ends in every process before blocking.

Use a small `ProcessOps` trait only for `kill`, `waitpid`, and sleep/clock behavior
required by `stop`; all namespace/mount calls remain concrete private functions.
On every pre-ready failure, send `Error(operation + errno context)` through the
status pipe, exit nonzero, remove the just-created JSON record in the host parent,
and attempt empty-cgroup cleanup.

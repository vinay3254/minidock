1. Executive Summary

EtherXMeet is a modern decentralized video conferencing and live collaboration workspace designed to combine standard consumer video usability (instant room join, screen sharing, zero setup friction) with Web3 cryptographic guarantees (on-chain state management, token-gated access, embedded gasless wallets, and verifiable IPFS meeting receipts).

Vinay G K led the architectural design and full-stack implementation as the sole core author across 26 commits, delivering smart contracts on Polygon, an interactive WebRTC signaling system, an embedded wallet subsystem, and high-performance in-browser collaboration engines.

Core Engineering Deliverable: A production-grade decentralized meeting suite that allows standard users to join frictionless conferences instantly, while enabling Web3 power users to leverage token gating, on-chain attendance verification, and automated NFT receipt minting.

2. End-to-End System Workflow

The system workflow spans five connected stages across the client, backend signaling gateway, and Polygon smart contracts:

1 Authentication & Embedded Wallet Initialization
  • User signs in via standard credentials (JWT) or Google OAuth.
  • WalletContext auto-initializes an encrypted client-side ethers.js wallet in localStorage.
  • The backend operator faucet drips gas (MATIC/POL) to new accounts via POST /api/wallet/fund on Polygon Amoy.
  • MetaMask or Web3 hardware wallets can be seamlessly attached without breaking standard flows.
2 Meeting Provisioning, Token Gating & On-Chain Creation
  • Host creates a room and configures meeting rules (token gates, password protection, recording permissions).
  • If token gating is enabled, TokenGateModal validates attendee ERC-20 / ERC-721 token balances on-chain.
  • Host anchors the meeting on Polygon via MeetingRegistry.createMeeting(meetingId, metadataCID).
3 WebRTC Mesh Conferencing & Signaling Gateway
  • Participants enter the room; backend/src/signaling.js manages peer room allocations over Socket.IO.
  • The client-side useWebRTC hook establishes peer-to-peer mesh connections with ICE candidate trickle and track renegotiation.
  • Audio, video, and screen-sharing tracks render in adaptive responsive video grid / filmstrip layouts.
4 Real-Time Audio, Speech & Productivity Suite
  • Live Transcript: Continuous speech-to-text with timestamps and speaker attribution via Web Speech API.
  • Ambient Sound Mixer: 8 client-side synthesized soundscapes generated procedurally via Web Audio API.
  • Interactive Whiteboard: Collaborative multi-user canvas with live socket synchronization.
  • Smart Agenda Timer: Section-by-section countdown tracking with overtime alarms.
  • Meeting Analytics: Real-time engagement score, speaker talk-time distribution, and live word clouds.
5 Session Finalization, IPFS Pinning & POAP Minting
  • Screen recordings (.webm) captured via MediaRecorder are uploaded and served via authenticated blob streams.
  • Host concludes meeting on-chain via MeetingRegistry.endMeeting(meetingId, notesHash).
  • Rich session metadata and AI summaries are pinned to IPFS via Pinata.
  • Host and attendees mint a verifiable ERC-721 receipt / POAP badge via MeetingNFT.mint(meetingId, ipfsCid).

3. Detailed Subsystem Breakdown

3.1 Solidity Smart Contracts (Polygon Amoy & Mainnet)

Contract Type Key Features & Architecture
MeetingRegistry.sol Custom State Machine Full lifecycle state tracking: createMeeting(), joinMeeting(), sendMessage(), endMeeting(). Emits indexing events with IPFS CIDs and keccak256 notes hashes.
MeetingNFT.sol ERC-721 URIStorage Verifiable proof-of-attendance receipt minter: mint(meetingId, ipfsCid). Cryptographically validates caller host permissions against MeetingRegistry on-chain.

3.2 WebRTC & Conferencing Hub

Vinay engineered the real-time core with a custom useWebRTC hook handling peer connections, track management, active speaker detection, and automatic ICE renegotiation, paired with the VideoRoom.jsx control center coordinating 20+ side panels and presentation modes.

3.3 In-Room Productivity & Procedural Audio

Created an in-browser productivity suite including LiveTranscript.jsx (speech-to-text with auto-scroll and export), AmbientSoundMixer.jsx (8 noise-synthesized soundscapes using Web Audio API), AgendaTimer.jsx (agenda countdown with overtime alerts), and MeetingAnalytics.jsx (talk-time breakdown & health metrics).

3.4 Embedded Wallet & Gasless UX

Designed an automatic client-side ethers.js wallet generated on signup, paired with an operator drip faucet (POST /api/wallet/fund) to grant new users instant testnet MATIC/POL gas without external wallet hurdles.
